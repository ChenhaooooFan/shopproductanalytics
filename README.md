# NailVesta 链接数据深度分析

TikTok Shop 运营数据（product analysis list 每日导出）+ 达人组数据（Creators / Products / Videos / LIVE）的深度分析工具。

## 部署到 Streamlit Community Cloud

1. 这个仓库直接 Deploy，Main file 填 `nailvesta_link_analytics_app.py`。**`.streamlit/config.toml` 这个文件也要一起上传**（配色主题在里面，是 GitHub 默认不显示但会上传的隐藏文件，直接拖进网页上传框，或者用 git 推的话本来就会带上）。
2. **部署后必须做**：App 右下角 ⋮ → **Settings → Secrets**，粘贴下面这段，把 `xxx` 换成真实值（**只有你自己能看到这个 Secrets 页面，不会进代码仓库、不会给访问者看到**）：

   ```toml
   LARK_HOST = "Lark 国际版 (larksuite.com)"
   LARK_BASE_URL = "https://qusjdzq12vah.sg.larksuite.com/base/XwZwbY0NTairFWsejC3lr0zjg0t"
   LARK_APP_ID = "xxx"
   LARK_APP_SECRET = "xxx"
   ```

   达人组数据跟运营数据是同一个租户，同一份 App ID/Secret 会自动沿用，不用重复填 `CREATOR_APP_ID`/`CREATOR_APP_SECRET`。

3. 打开 App，侧边栏「① 测试连接」确认能连上，再点「② 🔄 从 Base 拉取全部」和「🔄 拉取达人组数据」。

## 已知限制（公开部署 vs 本地跑的区别）

- **每次容器重启缓存会清空**：Streamlit Cloud 的磁盘不是永久的，应用长时间没人访问会休眠，醒来后本地缓存的文件都没了，得重新点一次拉取（运营数据和达人组数据各 180 多个文件，全新拉取大概各要 3–5 分钟）。本地跑不会有这个问题，缓存永久存在硬盘上。
- **App Secret 安全**：侧边栏的 App ID / App Secret 输入框现在**故意留空**，哪怕 Secrets 里配置好了也不会回显——因为 Streamlit 的密码框只是界面上显示圆点，真实值还是会发到浏览器，公开给别人访问的话谁都能在控制台里看到。现在这样改了之后，配置好 Secrets 就会在服务器这边悄悄生效，输入框全程看不到任何真实值。

## 页面结构（2026-09-23 改版：运营 / 达人 同一套页面）

侧边栏**最上面是「运营 / 达人」开关**，下面是同一套页面——开关切的是数据源，不是页面。两边的分析结构、图表、归因方法完全一样，只是换数据：
- **总览**：核心指标卡片 + 最近7天一句话结论（点名链接；达人版还点名达人）+ 快捷入口 + 大盘趋势 + 渠道结构
- **深度分析**：两段对比·归因／多粒度对比／前端指标／后端指标
- **监控与溯源**：异常检测与归因／链接下钻／日环比链条&回暖／改动效果溯源
- **参考**：指标归档
- **达人独有**（只在切到「达人」时出现）：达人 / 内容排行——本期 vs 基期、谁拉动谁拖累、集中度、新起量 / 掉线

**达人数据怎么"照搬"运营的分析**
- 链接 = 达人组 Products 表的 Product ID（跟运营是同一批链接、同一个名字），逐链逐日的达人 GMV 跟运营日报「达人渠道 GMV」99.6% 一致。
- 漏斗一样：GMV = 曝光 × CTR × CTOR × 客单价（达人侧 CTOR = 订单 ÷ 点击）。
- 渠道 = 达人视频 / 达人直播 / 商品卡及其他。按链接拆的视频/直播 GMV 用运营日报里的精确值（没载入运营日报时用挂车关系估算，页面会标注）。
- 运营没有、达人独有的维度也放进了归因：**按达人拆**（Creators 表，精确）、**按视频/直播拆**（每条内容精确）、**这条链是哪些达人在推**（挂车关系，近似：视频带来的成交里买家可能买了别的链接）。
- 「前端 / 后端」页除了按链接的字段，还能看达人表 / 视频表 / 直播表每一个原始字段的每日合计（完播率、互动率、观看时长这类按播放/观众加权）。

**运营页里自动附「达人侧原因」**（两边数据都拉了才会出现）：两段对比、异常检测、日环比链条里，只要某条链的变化主要在「达人」渠道，就在下面单独列出这条链在达人组数据里的原因——新发视频 / 发布达人 / 出单达人每天怎么变的、哪几个挂车达人停了或起量了。「两段对比」最下面还有一块达人侧同期对照。达人组数据比运营日报更新慢，所选时间段没被达人数据覆盖一半以上时会直接说明，不下结论。

配色主题在 `.streamlit/config.toml`（深色系 + 品牌粉红色 `#C2416B` 强调色，跟图表里"达人"渠道的颜色是同一个色，界面和图表统一视觉）。想换颜色就改这个文件的 `primaryColor` 等几行，不用碰代码。
